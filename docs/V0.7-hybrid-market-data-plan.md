## 3. 供應商驗證（公開文件，不代表已開通）
- **Fugle 台股**：免費基本用戶有 5 個 WebSocket 訂閱額度與 60/min 日內 API；開發者 300 訂閱、600/min 日內 API，且可取市場快照。每個「股票 × 訂閱頻道」計算為一個訂閱；要分鐘 K 加成交頻道需要額外額度。官方文件列開發者方案 NT$1,499/月，費率以實際訂閱頁面為準。
- **Fugle 台灣期權**：期權 WebSocket 與即時報價 API 已提供；基本用戶不含，開發者方案包含。期貨夜盤時間歸屬需依官方 API 規格轉換，不能把夜盤日期強行等同日盤。
- **SGX TWN / MTWN**：商品可確認，SGX Derivatives Market Direct Feed (DMDF) 涵蓋 SGX 期權；但尚無可直接接入、**可轉發至此網站**的已確認供應商。SGX 官網延遲報價頁不等於取得自動擷取及再散播許可。
- **授權紅線**：Fugle 與 TWSE/TPEx/TAIFEX 公告均要求遵守交易資訊規範；未收到對應書面權利說明前，不能透過公開網站重新傳送即時報價或將私人 API Key 放進前端。授權確認清單包含：私人本人使用 vs 公開揭示；非揭示分析；衍生數據；儲存歷史；延遲再發布；API 配額；實名用戶權限；台股／台灣期貨／SGX 各別收費。

## 4. 部署分層（正式採購授權前，不產生公開即時報價）
```text
             原有 GitHub Pages / 靜態股 V0.6.8.2 盤後功能
              ├── 多空排行 / 個股查詢 / 法人籌碼 / 07:00 計畫（原封不動）
              └── V0.7 新增盤中雷達 / 期貨面板（先以無行情狀態呈現）
                                     │
                          [有權限才啟用] HTTPS / WSS
                                     │
                 私有認證 API Gateway / 數據品質層 / 節流與快取
                    ├── 台股 WebSocket 重點自選
                    ├── 台股全市場 Snapshot 定時掃描
                    ├── TX / MTX 台灣期貨通道
                    └── SGX TWN / MTWN（找到授權供應商後才啟用）
```
- Github Pages **不放任何 API Key**。Key 存在環境秘密設定，並以權限／轉發授權限制使用者與標的。
- Cloudflare Workers 可作 HTTPS 快取及驗證層；若持續連外 WebSocket 需測試服務生命週期和／或使用受控常駐 Node.js 服務，不能假定普通 Cron＝永久串流。
- 靜態頁面維持原 PWA；新行情請求失敗不影響盤後排行榜顯示。避免把未認證的個人即時行情變成公開可取用接口。

## 5. 統一資料欄位與品質關卡
建議新通道共用模型：
```json
{
  "instrument": "TX|MTX|TWN|MTWN|2330",
  "market": "TAIFEX|SGX|TWSE|TPEX",
  "contractMonth": "YYYYMM or null",
  "tradingSession": "day|night|closed|unknown",
  "price": null, "volume": null, "currency": null,
  "source": "provider-id",
  "sourceEventAt": "ISO8601 with offset",
  "receivedAt": "ISO8601 with offset",
  "lastGoodAt": "ISO8601 with offset",
  "dataStatus": "REALTIME|DELAYED|EOD|STALE|UNAVAILABLE",
  "declaredDelaySeconds": null,
  "licensedForDisplay": false
}
```
- UI 必須同時顯示**行情交易日／事件時間／取得時間／來源／即時或延遲狀態**，絕不可用畫面刷新時間取代行情時間。
- 空值保持 `null`；連線中斷標示 STALE，保留上一筆的原始時間戳；超過可設定門檻（初始建議重點行情 30 秒、批次行情 2 倍輪詢間隔）停止發布任何新「突破訊號」。
- 期貨合約滾動以交易所合約與到期日判斷；TX、MTX、TWN、MTWN 各自保留月份、盤別、貨幣與計價單位，不得直接拼成相同點位或 K 線。
- 盤中未收盤分 K 只能標為暫定；正式日 K 與隔日 07:00 推薦仍以已確認的盤後資料產生。
- 個股的成交量／內外盤、法人、自營商、官股需各有正式來源、時間、單位；不得以估值冒充正式值。

## 6. UI 與功能清單
- **盤中雷達**（沿用 `#page-intraday` 預留區）：自選 10–30 檔、當日價量、分鐘 K、突破判定、5/10/15/30 分鐘多頭共振、行情狀態及更新時間；無權限時明確顯示「未接入行情」。
- **全市場掃描**：保留 1,991 檔盤後總清單；只有完成盤中快照覆蓋率驗證時，才輸出盤中排行。漏股與跨時段資料不得參與同批比較。
- **期貨監控**：TX/MTX/TWN/MTWN 四塊獨立報價，切換日夜盤、正確契約月份、期貨漲跌與來源時間；可計算方向共振但不能以 SGX 點位直接推定台灣加權點數。
- **個股查詢／來源頁**：額外標示盤中與盤後資料的分界及歷史補齊進度，不變更原本計算公式。

## 8. 優先次序／決策閘口
1. **P0 授權與費用**：詢問 Fugle（本人私有系統 vs 公開網站；行情再展示權）、SGX 授權供應商／代理商（TWN / MTWN 報價與 API、展示權、延遲模式）。在答覆前所有需授權的功能停留在 demo／不可用。
2. **P1 安全資料模型**：上線新 UI 預留區、資料狀態、時間戳記、品質門檻、環境秘密設定範本；不購買即時資料也可部署。
3. **P2 台股本人即時自選**：授權後接入 watchlist WebSocket，驗證多頻道訂閱數與行情事件。
4. **P3 TX/MTX 台灣期貨**：授權後接入期權 WebSocket，驗證換月與夜盤日期。
5. **P4 SGX 富台指**：**在已取得合法自動取數／揭示權的供應商後**再介接 TWN/MTWN；如果只有延遲資料授權則只顯示 DELAYED。
6. **P5 全市場掃描**：授權快照、錯誤重試、快取、5–15 分鐘輪詢、覆蓋率門檻與排名驗收。
7. **P6 正式試營運**：雙跑比對盤中與盤後、同日切換、API 用量和延遲告警、回退到舊版。
