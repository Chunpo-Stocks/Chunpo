股_V0.6｜親友共享免費台股多空篩股 APP（原型）
==============================================

【先體驗：你的 Windows 不用安裝任何軟體】
1. 將 ZIP 完整解壓縮。
2. 進入「股_V0.6」→「public」→雙擊 index.html。
3. 會顯示「人造示範資料」；可操作多空排行、W/M/V 型態條件、年線、搜尋、CSV 匯出、個股頁。
   注意：示範資料不是台灣真實股票行情，不能拿來交易。

【真正公開給親友，且自動抓盤後數據】
需由站長註冊一個「GitHub」免費帳號，將整個程式上傳為「公開存放庫」，啟用 GitHub Pages 和 Actions。
部署後親友只要開一個網址，不需安裝 Python / Node.js / BAT / ZIP。
完整步驟在 README_部署指南.md。

【盤中 1～5 分鐘行情目前未開通】
公開免費轉供券商即時行情可能違反授權條款；本版本不會製造假即時數據。
盤後資料來源：TWSE + TPEx 官方公開接口；在正式公開前要確認最新授權條件。

【首次 MA240 年線不是立即有】
正式站的首次抓取只建立最新盤後日線。
歷史需要後台分次回補至少約 250 交易日；畫面會顯示回補進度。
對少於 250 筆交易日的個股不計正式多空分數。

【驗證說明】
已測試：核心指標、樣本解析、年線不足保護、程式語法與檔案完整性。
本次環境無法直接連線台灣官方 API，因此尚未完成真實數據抓取測試；尚未部署到雲端。
