股_V0.6.3 — 法人籌碼觀察更新包

【本版實作】
1. 多空排行新增外資5日、投信5日淨買賣超（有資料時才顯示，單位張）。
2. 個股查詢新增外資、投信、自營商 5/20/60 日淨買賣超、有效資料覆蓋率與最近20交易日逐日進出。
3. 外資與投信「近20日淨買超日加權收盤參考價」和現價比較；這不是實際買入成本、持倉成本或主力成本。
4. 增加獨立法人歷史回補游標，不必重新抓取全部股價；上市 TWSE T86、上櫃 TPEx dailyTrade 由官方來源嘗試取得。
5. 若法人歷史少於所選交易日的80%，整段累計顯示「資料不足」，不以0代替。
6. 更新 PWA 靜態檔快取版本，保留原有 MA240、60日初步篩股、歷史資料庫與介面。

【重要限制】
此包為已測試規則與介面的程式更新包，尚未替你的 GitHub 網站部署；官方歷史法人 API 的實際回傳格式、限流與授權仍須在你的 Actions 中驗證。
主力分點與真實庫存成本目前沒有資料來源；不會捏造。股價回補與法人回補使用不同游標；法人成本「參考價」只是淨買超日收盤價加權估計，並非任何人的實際成本。

【GitHub 更新】
1. 完整解壓 ZIP，不要直接上傳壓縮檔。
2. 到 https://github.com/Chunpo-Stocks/Chunpo 的 Code → Add file → Upload files。
3. 將壓縮包內的 engine.mjs、package.json、public、scripts、test、.github 依原路徑覆蓋到儲存庫根目錄。
4. Commit changes。注意 .github/workflows/publish.yml 必須在正確位置，不能變成根目錄 publish.yml。
5. 別刪掉既有 store/history.json.gz。修正包也未包含 store 資料庫，不會刻意清空歷史。
6. 在 Actions → 股 V0.6 每日盤後更新與發布 → Run workflow，第一次先使用 backfill_days=0、chip_days=20。
7. 完成後到 https://chunpo-stocks.github.io/Chunpo/，強制重新整理、點排行榜的股票或「個股查詢」→ 查詢代號。
8. 如果資料不足，檢查「資料與說明」的法人補建回報。若 API 取不到資料，缺漏仍會顯示且留待重試；千萬不要把空值視為成本0。

【預期建置進度】
首次 chip_days=20 至多掃描20個已有日線的交易日，可能需再次執行才能建立60日籌碼。官方來源失敗時會在執行紀錄與資料說明頁看到訊息，不保證首次成功取得全部資料。

Node 程式單元測試：27/27 通過；本機網頁注入測試：桌機及390px手機介面、7個籌碼欄位、20列歷史及瀏覽器 JavaScript 無錯誤。此測試使用人造示範股票，並非官方即時行情連線測試。
