股_V0.6.5 — 大盤 / OTC / 台指期 / 融資券 / 斐波 研究功能
=========================================================

這是 V0.6.4 的增量更新包，不是需在 Windows 安裝的應用程式。
你的正式網站仍是 https://chunpo-stocks.github.io/Chunpo/

【更新方式】
1. 解壓「股_V0.6.5_修正包.zip」。
2. 進入 GitHub https://github.com/Chunpo-Stocks/Chunpo 的 Code 頁，Add file → Upload files。
3. 把修正包中的 scripts、public、test、.github 資料夾及 package.json 拖進上傳畫面。
   請保留子資料夾路徑，不要直接上傳 ZIP，也不要額外包一層同名資料夾。
4. 按 Commit changes。
5. 確認 GitHub 主目錄有 scripts/market-engine.mjs，以及 public/index.html。
6. 到 Actions 選「股 V0.6.5 每日盤後更新與發布」，手動執行一次。
   backfill_days=0；chip_days=0（先確認新增五項盤後來源是否能順利解析）。
7. 工作流程成功後開啟 APP 並 Ctrl+F5，確認頁首顯示「股_V0.6.5」。
   新增「大盤／斐波／融資券」分頁；個股查詢新增斐波和融資券資料。
8. 請到「資料與說明」確認各來源，尤其期貨及融資券是否有解析失敗警告。

【重要：不要覆蓋或刪除】
- store/history.json.gz：現有完整個股歷史資料庫，更新包並未包含此檔。
- public/data/ 目前由 Actions 自動產生的行情資料：更新包並未包含該資料夾。

【設計範圍】
- 加權：證交所指數 OpenAPI 歷史月內資料，逐日累積。
- OTC：櫃買指數 OpenAPI 最近幾筆，逐日累積。首次可能不足 20/60 日。
- 台指期：期交所最新盤後 TX 近月，嚴格分開日夜盤和契約月份。
- 融資融券：TWSE / TPEx 最新盤後快照，按最新交易日存入既有資料庫。
- Fibonacci：個股近 60/120 交易日、指數近 20/60/120 交易日，極值錨點、回撤、延伸及假設時間窗；不保證轉折。
- 此版本不是每 1～5 分鐘即時行情，仍為官方盤後資料。
- 免費官方 OpenAPI 有時只回最新資料，不支援指定日期回補。首次建立長期歷史須持續累積；不捏造缺漏值。
- 目前程式與模擬來源已通過本機測試，但官方五項新來源的實際欄位及 GitHub 線上執行尚須驗證。
- 融資融券數量的來源單位暫時保留原值並標示待核，不跨市場直接加總；盤後信用餘額不是主力持股成本。

【看到「資料不足」】
不要重複按下回補；先點 Actions → 最新執行 → publish → 展開「向官方取數」步驟，找到「市場資料 taiex / otc / tx / twseMargin / tpexMargin」，確認是抓到幾筆還是解析警告。
若來源發生格式改版，請貼詳細錯誤給我，將依實際回應修正，不會猜數據。
